How ForensiTriage Works

A structured four-step process from case creation to FSL submission schedule.

1
Create Case
Open a new case with crime type, incident details, location, and lead investigator.
2
Log Evidence
Add each item of evidence with category, collection details, and supporting attachments.
3
Set Priorities

4
Generate Schedule

Classification System

Clear Priority Framework

Five distinct priority levels with consistent visual indicators across the entire platform.

Critical Requires immediate forensic attention. Urgent specialized testing required. Highest FSL queue priority.
High Significant evidence that should be examined promptly. Important for case progression.
Medium Standard priority. Should be examined in normal processing order.
Low Lower forensic urgency. Can be processed after higher priority items.
Unassigned Priority not yet reviewed. Investigator action required before FSL submission.
